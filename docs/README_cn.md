**README 数学公式 → 计算通道（passes）的映射：**

| 项                        | 含义       | Kernel（内核）                                                         |
| ------------------------- | ---------- | ---------------------------------------------------------------------- |
| **f**                     | 外力       | `splat.comp` — 拖拽时注入高斯速度冲量 + 色相循环染料                   |
| **ν∇²u**                  | 粘性       | `diffuse.comp` — $(I-\nu dt\nabla^2)u^{new}=u^{old}$ 的 Jacobi 迭代    |
| **−(1/ρ)∇p**, **∇·u = 0** | 压力投影   | `divergence.comp` → `pressure.comp`（Jacobi，热启动）→ `gradient.comp` |
